Publish & Share Your Own Bundles

OKF is 100% decentralized. Host your bundle on your own GitHub repository, tag it with okf-memory-bundle, and any AI agent or developer can vendor it immediately without permission or Pull Requests.

01

Create Any Git Repository

Initialize a public repository on GitHub (e.g. github.com/your-org/my-rules) with your domain decisions.

02

Author OKF Invariants

Add index.md, log.md, and Markdown decisions with okf_version: "0.2" and SemVer bundle_version.

03

Validate Strict

Run okf validate . --strict to guarantee zero errors, valid ISO dates, and fully connected graphs.

04

Tag & Get Indexed

Add GitHub topic okf-memory-bundle in repo settings and tag a release (git tag v1.0.0). Your bundle is instantly discoverable and pullable:

okf pull github.com/your-org/my-rules@v1.0.0
Official Repository Badge:

Embed the canonical badge in your repository's README.md to link your bundle directly to the registry:

[![OKF Memory Bundle](https://registry.okf-memory.dev/badge/v0.2.svg)](https://registry.okf-memory.dev)

🏷️ Tagging with okf-memory-bundle allows decentralized ecosystem discovery across GitHub.
